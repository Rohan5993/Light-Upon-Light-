# Free forever stack

## Live site

https://thelightuponlight.org/

## What is free (no card required)

| Piece | Service | Cost |
| --- | --- | --- |
| Website | GitHub Pages | Free |
| Blog | Files in this repo | Free |
| Contact / Volunteer / Appointment forms | FormSubmit → `lightuponlight1408@gmail.com` | Free |
| Donate | PayPal + EmailJS (optional) | Free tiers |

**Render / paid Strapi hosting is not required.** You can ignore upgrade prompts and even delete the Render service.

## Update blog posts

1. Edit `src/data/staticBlogPosts.json`
2. Put images in `public/blog/`
3. Push to `main` → GitHub Actions deploys

## First form submission

FormSubmit may send a one-time confirmation email to `lightuponlight1408@gmail.com`. Click confirm once, then submissions arrive in that inbox.
