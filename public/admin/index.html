One-time login setup needed

The “Not Found” message appears because GitHub login is not configured yet. A technical person must do this once (free):

  1. Open GitHub → New OAuth App
  2. Set Application name to Light Upon Light CMS
  3. Set Homepage URL to https://thelightuponlight.org
  4. Set Authorization callback URL to https://thelightuponlight.org/admin/
  5. Click Register application
  6. Copy the Client ID and send it to your developer (or paste it into public/admin/config.yml as app_id, then push to main)
  7. Invite editors as GitHub collaborators on Rohan5993/Light-Upon-Light- (Write access)

Until that Client ID is added, login cannot work. After it is added, refresh this page and use Login with GitHub.
